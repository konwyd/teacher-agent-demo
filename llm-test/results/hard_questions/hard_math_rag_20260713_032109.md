## Q1 — 解答题

**题目**: 题目内容: 已知b是满足其自身立方等于自身的唯一负整数，且a、b满足${{\left(a+3b\right)}^{2}}+\left|d+\frac{1}{3}\right|=0$，请回答下列问题：（1）直接写出a、b、d的值：$a=$__，$b=$__，$d=$__；（2）a、b、d在数轴上所对应的点分别为P、Q、R，点S是Q、R之间的一个动点（不包括Q、R两点），其对应的数为n，化简$\left|n+\frac{1}{3}\right|-|n-3|+|n+2|$；（3）在上述条件下，点P、Q、R开始在数轴上运动，若点Q以每秒一个单位距离向左移动，同时点P、点R都以每秒2个单位距离向右移动，

**参考答案**: 6；-1；-\frac{1}{3}；n-\frac{10}{3}；不变；\frac{8}{3}

**联网参考**: 🌐 Tavily AI 摘要 | 🌐 初中数学动点重难点题详解| PDF (https://www.scribd.com/document/835540604/%E5%88%9D%E4%B8%AD%E6%95%B0%E5%AD%A6%E5%8A%A8%E7%82%B9%E9%87%8D%E9%9A%BE%E7%82%B9%E9%A2%98-%E8%AF%A6%E8%A7%A3)

**学生答案**:

### 解答

（1）根据题意，b是满足其自身立方等于自身的唯一负整数，解得b = -1。代入方程(a + 3b)² + |d + 1/3| = 0，解得a = 3，d = -1/3。

（2）点P、Q、R分别位于3、-1、-1/3处，点S在Q和R之间，n的取值范围为-1 < n < -1/3。化简表达式得n - 4/3。

（3）点P、Q、R运动后，PQ = |4 + 3t|，QR = |2/3 + 3t|。计算PQ - QR得10/3，不随t变化。

最终答案：

（1）a=3，b=-1，d=-1/3；

（2）化简结果为n - 4/3；

（3）PQ - QR的值为10/3，不变化。

答案：
（1）a= \boxed{3}，b= \boxed{-1}，d= \boxed{-\dfrac{1}{3}}；

（2）\boxed{n - \dfrac{4}{3}}；

（3）\boxed{\dfrac{10}{3}}，不变化。
