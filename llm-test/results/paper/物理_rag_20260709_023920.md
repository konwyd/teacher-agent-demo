## 五、综合应用题(本题共2小题,第20题8分,第21题9分,共17分)

20. (1) **电磁**；**机械**

(2) 解：
拖拉机对水平田地的压力：
F = G = mg = 4.8×10³ kg × 10 N/kg = 4.8×10⁴ N

由p = F/S得：
S = F/p = 4.8×10⁴ N / (80×10³ Pa) = 0.6 m²

答：拖拉机与水平田地的总接触面积至少为0.6 m²。

(3) 解：
拖拉机匀速直线前进，牵引力F牵 = f = 3×10⁴ N
前进距离：s = vt = 2 m/s × 60 s = 120 m
牵引力做的功：W = F牵s = 3×10⁴ N × 120 m = 3.6×10⁶ J

答：牵引力做的功为3.6×10⁶ J。

21. (1) **减小**

(2) 解：
由电路图可知，R₀与Rt串联，电压表测R₀两端电压
当电压表示数为10V时，电流表示数为0.5A
R₀两端电压U₀ = 10V，通过R₀的电流I = 0.5A
R₀ = U₀/I = 10V/0.5A = 20Ω

由题意知R₀ = 10Ω，与计算结果不符，说明此时电压表测的是Rt两端电压
则Rt两端电压Ut = 10V
电路电流I = 0.5A
Rt = Ut/I = 10V/0.5A = 20Ω

由图乙可知，当Rt = 20Ω时，温度t = 40℃

答：此时水温是40℃。

(3) 解：
电流表量程0~0.6A，电压表量程0~15V
当电流最大为0.6A时，电路总电阻R总 = U/I = 15V/0.6A = 25Ω
Rt = R总 - R₀ = 25Ω - 10Ω = 15Ω
由图乙可知，此时温度约为50℃

当电压表示数最大为15V时，R₀两端电压U₀ = 15V
电路电流I = U₀/R₀ = 15V/10Ω = 1.5A > 0.6A，超过电流表量程
所以应以电流表量程为限制条件
Rt = 15Ω时，由图乙可知温度约为50℃

答：该装置能测量的最高水温约为50℃。

(4) 选择**甲方案**。
理由：适当减小电源电压，在电流不超过0.6A的情况下，电路总电阻减小，Rt可以更小，由图乙可知Rt越小温度越高，所以能测量的最高水温提高。而乙方案减小R₀，会使电流更大，更容易超过电流表量程，不利于提高测量上限。
