18. (9分)
解：设这本书的长度为 x 尺，小文的一拳长为 y 尺。
根据题意，得：
x + y = 1
2x = 3y + 1
解方程组，将 y = 1 - x 代入第二个方程：
2x = 3(1 - x) + 1
2x = 3 - 3x + 1
5x = 4
x = 0.8
则 y = 1 - 0.8 = 0.2
答：这本书的长度是 0.8 尺，小文的一拳长是 0.2 尺。

19. (9分)
(1) 作图如下：
以点 C 为圆心，以 AE 长为半径画弧，交 CD 于点 G；再以点 C 为圆心，以 AB 长为半径画弧，交前弧于点 H；连接 CH 并延长交 AD 于点 F。则 ∠DCM 即为所求。

∴ AF = CE。
∵ AD = BC，
∴ AD - AF = BC - CE，即 DF = BE。

22. (10分)
(1) ∵ 点 A(0, -3) 在抛物线 y = x² + bx + c 上，
∴ c = -3。
∵ 点 B 是点 A 的“黄金搭档点”，
∴ 点 B 的横坐标为 0 + 3 = 3。
又 ∵ 点 B 的纵坐标为 12，
∴ 点 B 坐标为 (3, 12)。
将 (3, 12) 代入 y = x² + bx - 3，得 9 + 3b - 3 = 12，解得 b = 2。
∴ b = 2，c = -3。

(2) 抛物线解析式为 y = x² + 2x - 3。
设点 M 的横坐标为 m，则点 N 的横坐标为 m + 3。
① ∵ 点 M, N 的纵坐标相等，
∴ m² + 2m - 3 = (m + 3)² + 2(m + 3) - 3。
化简得 m² + 2m - 3 = m² + 6m + 9 + 2m + 6 - 3
m² + 2m - 3 = m² + 8m + 12
-6m = 15
m = -2.5
∴ 点 M 的横坐标为 -2.5，点 N 的横坐标为 -2.5 + 3 = 0.5。
② m 的值为 -1 或 -4。
