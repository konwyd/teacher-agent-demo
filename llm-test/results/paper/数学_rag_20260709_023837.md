19. (9分)

    (1) 作图：
    以点 C 为顶点，以 CD 为一边，作 ∠DCM = ∠BAE，射线 CM 交边 AD 于点 F。
    (作图步骤：1. 以A为圆心，适当长为半径画弧，交AB、AE于两点；2. 以C为圆心，相同半径画弧，交CD于一点；3. 以该交点为圆心，以AB、AE上两交点距离为半径画弧，与前弧交于一点；4. 过C和该交点作射线，交AD于F。)

    (2) 线段 BE 与 DF 的数量关系是：BE = DF。
    证明：
    ∵ 四边形 ABCD 是平行四边形，
    ∴ AB ∥ CD，AD ∥ BC，AB = CD，AD = BC。
    ∵ ∠DCM = ∠BAE，
    ∴ AE ∥ CF (同位角相等，两直线平行)。
    ∴ 四边形 AECF 是平行四边形 (两组对边分别平行)。
    ∴ AF = CE。
    ∵ AD = BC，
    ∴ AD - AF = BC - CE，
    即 DF = BE。

22. (10分)

    (1) 由题意，点 B 的横坐标为 0 + 3 = 3，纵坐标为 12。
    将 A(0, -3) 和 B(3, 12) 代入 y = x² + bx + c 得：
    c = -3
    9 + 3b + c = 12 => 9 + 3b - 3 = 12 => 3b = 6 => b = 2
    ∴ b = 2, c = -3。

    (2) 抛物线为 y = x² + 2x - 3。
    ① 设 M 的横坐标为 m，则 N 的横坐标为 m + 3。
    ∵ M, N 纵坐标相等，
    ∴ m² + 2m - 3 = (m+3)² + 2(m+3) - 3
    化简得：m² + 2m = m² + 6m + 9 + 2m + 6
    0 = 6m + 15
    m = -5/2
    ∴ M 的横坐标为 -5/2，N 的横坐标为 1/2。

    ② m 的值为 -2 或 -1。

23. (10分)

    (1) ∠BEH 的度数为 30°，CH 的长为 4。

    (2) 两个结论仍然成立。
    证明：
    连接 AC，BD 交于点 O。
    ∵ 菱形 ABCD，∠BAD = 120°，
    ∴ ∠ABC = 60°，AB = BC = CD = AD。
    ∴ △ABC 和 △ADC 是等边三角形。
    ∴ AB = AC，∠BAC = 60°。
    由旋转知，AB = AE，∠BAE = α。
    ∴ AE = AC。
    ∵ ∠CAE = ∠BAC - ∠BAE = 60° - α，
    ∠DAE = ∠BAD - ∠BAE = 120° - α，
    ∴ ∠DAC = 60°。
    ∴ ∠DAE - ∠DAC = (120° - α) - 60° = 60° - α = ∠CAE。
    即 ∠CAE = ∠DAE - ∠DAC。
    在 △ABE 和 △ACH 中，
    AB = AC，AE = AC，∠BAE = ∠CAE = 60° - α，
    ∴ △ABE ≌ △ACH (SAS)。
    ∴ BE = CH，∠ABE = ∠ACH。
    ∵ BH = BE，
    ∴ BH = CH。
    在 △ABD 中，∠ABD = 30°。
    ∴ ∠ACH = ∠ABE = 30°。
    ∴ ∠BCH = ∠ACB + ∠ACH = 60° + 30° = 90°。
    ∴ △BCH 是等腰直角三角形。
    ∴ ∠CBH = 45°。
    ∴ ∠EBH = ∠CBH - ∠CBE = 45° - (∠ABC - ∠ABE) = 45° - (60° - 30°) = 15°。
    ∵ BH = BE，
    ∴ ∠BEH = ∠BHE = (180° - ∠EBH)/2 = (180° - 15°)/2 = 82.5°。
    此结论与(1)中30°不符，说明上述证明过程有误。
    重新证明：
    连接 AC。
    由旋转知，AB = AE，∠BAE = α。
    ∵ 菱形 ABCD，∠BAD = 120°，
    ∴ AB = BC = CD = AD，∠ABC = 60°。
    ∴ △ABC 是等边三角形。
    ∴ AB = AC，∠BAC = 60°。
    ∴ AE = AC。
    ∵ ∠EAC = ∠BAC - ∠BAE = 60° - α，
    ∠DAC = 1/2 ∠BAD = 60°。
    ∴ ∠DAE = ∠DAC + ∠CAE = 60° + (60° - α) = 120° - α。
    在 △ABE 和 △ACD 中，
    AB = AC，AE = AD，∠BAE = ∠CAD = α，
    ∴ △ABE ≌ △ACD (SAS)。
    ∴ BE = CD = 4，∠ABE = ∠ACD = 30°。
    ∵ BH = BE = 4，
    ∴ BH = CD。
    连接 BD。
    ∵ 菱形 ABCD，∠BAD = 120°，
    ∴ BD 垂直平分 AC，∠ADB = 30°。
    ∴ ∠BDE = ∠ADB + ∠ADE。
    在 △ADE 中，AE = AD，∠DAE = 120° - α，
    ∴ ∠ADE = (180° - (120° - α))/2 = (60° + α)/2 = 30° + α/2。
    ∴ ∠BDE = 30° + 30° + α/2 = 60° + α/2。
    ∵ ∠BDC = 30°，
    ∴ ∠CDE = ∠BDE - ∠BDC = 30° + α/2。
    在 △BHE 中，BH = BE = 4，∠HBE = ∠ABE + ∠ABC = 30° + 60° = 90°。
    ∴ △BHE 是等腰直角三角形。
    ∴ ∠BEH = 45°，HE = 4√2。
    ∵ ∠BED = ∠BHE + ∠EBH = 45° + 45° = 90°。
    ∴ ∠HED = ∠BED - ∠BEH = 90° - 45° = 45°。
    ∴ ∠HED = ∠BHE。
    ∴ HE ∥ BD。
    ∴ ∠HEC = ∠DBC = 30°。
    在 △HEC 和 △DBC 中，
    HE = 4√2，BD = 4√3，EC = BC - BE = 4 - 4 = 0，此路不通。
    重新审视：当 α=30°时，∠BAE=30°，∠EAC=30°。
    ∵ AB=AC，AE=AC，∠BAE=∠EAC=30°，
    ∴ △ABE ≌ △ACE (SAS)。
    ∴ BE=CE。
    ∵ BH=BE，
    ∴ BH=CE。
    连接 CH。
    ∵ ∠ABC=60°，∠ABE=30°，
    ∴ ∠EBC=30°。
    ∴ ∠BEC=120°。
    ∵ ∠HBE=90°，
    ∴ ∠HBC=60°。
    ∴ ∠HBC=∠ECB=60°。
    又 BH=CE，BC=CB，
    ∴ △HBC ≌ △ECB (SAS)。
    ∴ CH=BE=4。
    ∵ △BHE 是等腰直角三角形，
    ∴ ∠BEH=45°。
    这与(1)中30°矛盾，说明(1)中结论有误。
    更正：(1) ∠BEH 的度数为 45°，CH 的长为 4。
