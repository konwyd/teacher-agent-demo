# Teacher Agent — 教育领域 RAG 知识增强系统

## 项目概述

设计并实现了一个面向 K9 教育的 **RAG（检索增强生成）知识库系统**，搭载 **28.8 万条多模态知识库**（涵盖 19 个学科教材、22.5 万道题库、课程标准、教师资格证），结合大语言模型实现"开卷考试"式智能答题。

## 核心技术

- **混合检索架构**：自研 BM25（关键词）+ bge-m3（语义向量）双路检索，RRF 融合排序，解决了纯语义检索对精确术语匹配不足的问题
- **向量检索引擎**：基于 ChromaDB + HNSW 近似最近邻索引，支持 1024 维向量的毫秒级检索
- **自适应上下文注入**：对标 GPT-4/Claude 主流方案，去掉硬截断，全量注入候选资料让 LLM 自行判断相关性
- **多级检索策略**：教材原文 → 题库匹配 → Tavily 联网搜索三级回退，本地相似度不足时自动触发联网

## 消融实验结果（化学中考真题，答案已删除）

| 实验配置 | 得分 | 分析 |
|---|---|---|
| ① 纯模型 | 43 分 | DeepSeek-v4-flash 裸答基线 |
| ② 模型 + 本地 RAG | **48 分** | 教材+题库，+12% |
| ③ 模型 + 本地 RAG + 联网 | **50 分** | 本地+联网，+16% |

**结论**：本地 RAG 稳定增益 12%，联网额外贡献 4%，本地知识库是核心价值。
