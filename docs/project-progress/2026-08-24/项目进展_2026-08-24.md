## 2. 当前架构与主链路

### 2.1 运行时分代

主链路：

```text
8502 Streamlit
  → 读取账号、会话、工作上下文和学生记忆
  → deterministic fast route 或 LLM classifier
  → deterministic plan / classifier-direct / bounded dynamic agent
  → 受控 Skill、Local RAG、Quality-QA、Web RAG
  → 本地收紧 TeachingContract
  → 可选 deterministic verifier
  → Teacher LLM 生成回答
  → 风险分级审计、硬边界复核和条件修正
  → Reasoning Trace、turn record、会话与记忆 writeback
  → 8502 页面展示
```

冻结 baseline：

```text
8501 / 8000
  → app/agent/workflow.py
  → diagnose → retrieve → teaching_policy → teach → memory_update → log
```

新功能只进入 8502；legacy 只接受 regression fix 和 critical fix。

### 2.2 当前可观察路由

当前未提交 Runtime 实现包含四类路由：

1. `deterministic_fast_path`
2. `model_classifier_direct_path`
3. `dynamic_agent_path`
4. `memory_clarification_reply`

当前调用预算回归用例验证：

| 回归场景 | 模型调用 |
|---|---:|
| 明确题外请求 | 0 |
| “勾股定理是什么”这类确定性简单概念 | Teacher 1 次 |
| Fast Miss 但分类后可直接规划的普通 K9 概念 | Classifier + Teacher，共 2 次 |
| 动态联网课程标准用例 | Action Provider + Teacher + Audit，共 3 次 |

这些数字是当前测试覆盖场景的实际断言，不代表所有异常、截断或 repair 情况的绝对上限。

### 2.3 核心权威边界

- `math_checker` 在适用范围内裁决数学步骤和答案正确性。
- TeachingContract 决定教学目标、题目应用和最终答案披露权限。
- Memory、RAG、Quality-QA 和历史内容都是软参考，不能覆盖 checker 或 TeachingContract。
- Memory V2 admission/controller 仍为 shadow，不能授权、阻止或改变 baseline write。
- UI 只展示白名单公开决策摘要，不保存或展示 private reasoning。
- 所有生产 LLM 调用必须经过 `app/llm/deepseek_client.py`。
