# RAG 消融实验对比报告

> 实验日期：2026-07-20  
> 测试对象：2026 年河南省中考化学试卷（答案已从知识库中删除）  
> 评测模型：DeepSeek-v4-flash（考生）+ DeepSeek-v4-flash（阅卷）  
> 满分：50 分

---

## 一、实验设计

在化学中考真题**答案已从向量库中删除**的条件下，仅保留纯试卷题目，进行三组对照实验，验证各组件的独立贡献：

| 组别 | 配置 | RAG 检索 | 联网搜索 |
|---|---|---|---|
| ① 纯模型 | 无 RAG | ❌ | ❌ |
| ② 模型 + 本地 RAG | BM25 + bge-m3 + RRF | ✅ | ❌ |
| ③ 模型 + 本地 RAG + 联网 | ② + Tavily auto | ✅ | ✅ |

## 三、逐项分析

### 3.1 纯模型（43 分）

DeepSeek-v4-flash 不借助任何外部知识，完全依赖训练时学到的化学知识作答。

- **说明**：模型本身对初中化学有较好的掌握，裸答 43/50 分（86% 正确率）
- **不足**：部分需要教材原文精确记忆的题目（如化学方程式配平、特定实验步骤）可能出错

### 3.2 本地 RAG（48 分，+12%）

在纯模型基础上，增加了 BM25 + bge-m3 混合检索，从本地向量库中检索教材知识点和相似题库题目作为参考。

检索到的资料包括：
- 教材片段：化石燃料、元素符号、化学方程式、实验操作等
- M3KE 题库：化学与环境保护、物质分类、化学计算等相似选择题
- 中考真题（纯题目，无答案）：2026 年化学试卷原文

**增益分析**：
- 教材知识点帮助模型确认概念定义（如"绿色化学""清洁能源"）
- M3KE 相似题提供了答题思路参考
- 中考真题原文让模型了解试卷结构和题型

**局限**：
- 中考真题没有答案，模型仍需自己计算
- 教材片段是通用知识点，不是逐题精准匹配
- 整卷一次 RAG 的 query 噪音问题依然存在

### 3.3 本地 RAG + 联网（50 分，+16%）

在本地 RAG 基础上，当本地检索结果相似度不足时（阈值 0.65），自动触发 Tavily 联网搜索。

**联网贡献（+2 分 vs 纯本地）**：
- 互联网上能搜到部分化学知识的补充解释
- 边际增益较小（+4%），说明本地知识库已经覆盖了大部分需要的知识
- 联网质量取决于搜索引擎返回内容的可靠性

## 四、核心结论

### 4.1 本地 RAG 是核心价值来源

| 组件 | 贡献 |
|---|---|
| 纯模型能力 | 43 分（基线 86%） |
| 本地 RAG 增量 | +5 分（总贡献的 71%） |
| 联网增量 | +2 分（总贡献的 29%） |

本地 RAG 提供了 71% 的增益，是系统的核心价值。

### 4.2 联网是补充而非替代

联网在本地基础上额外贡献 +4%，说明：
- 本地精选知识库的质量和覆盖度已经很高
- 联网适用于本地知识库完全无法覆盖的边缘场景
- 在教育等封闭领域，**精选知识库 > 开放网络搜索**

### 4.3 基础模型能力不容忽视

deepseek-v4-flash 裸答 43 分，占满分的 86%。这提醒我们：
- 大模型本身已经具备相当强的知识储备
- RAG 的价值在于补齐模型不擅长的精确记忆和最新知识
- 好的 RAG 系统应该"锦上添花"而非"雪中送炭"

---

## 五、后续优化方向

1. **逐题 RAG**：当前整卷一次检索，query 噪音大。改为逐题拆分后分别检索，预计可进一步提升
2. **知识库扩充**：补充更多教材版本和历年真题，提高覆盖度
3. **联网质量控制**：对 Tavily 搜索结果增加来源可信度评分，过滤低质量内容
4. **本地模型部署**：在 8×4080 上部署 int4 量化模型，降低延迟和成本
