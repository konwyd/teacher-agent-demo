# 提问处理流程 · 通俗说明

> 这份文档面向不看代码的人：用大白话讲清楚"学生发一条消息，系统是怎么一步步把它变成老师回复的"。
> 想追到代码级细节的，请看 [8502 Teacher Agent Loop 全链路说明](./8502_Teacher_Agent_Loop_全链路说明.md)。

## 一句话总结

**判断它是什么 → 决定怎么教 → 需要就翻教材 → 组织回答 → 更新记忆。**

你在页面上看到的那四格"备课批注"（题意 / 写法 / 资料 / 成稿），就是系统做这几件事的实时画面。

---

## 完整过程：学生问 "方程 2x+3=11 怎么解?"

### 第 1 步：学生按了发送

页面把这句话交给后端处理，同时带上两个"身份信息"：

- 这是**谁**在问（哪个账号）
- 这是**哪一次会话**（哪节课）

这两个信息很重要——系统靠它们判断：这是"新的一节课"，还是"上节课的继续"。

### 第 2 步：先判断"这算什么事"（一瞬间，不用动脑子）

系统先不看 AI，而是用几条死规则快速对号入座：

- 是打招呼吗？（"你好""谢谢"）→ 直接回一句客套话，完事。
- 是明显扯到课程外了吗？（"帮我推荐个手机"）→ 直接把他拉回课程，完事。
- 是在追问刚才那道题吗？（"这一步怎么来的"）→ 按"续题"处理。
- 话里有没有明确学科？（"方程"→数学、"作文"→语文）→ 按"数学/语文新题"处理。

上面这句带了"方程"，命中了"数学"学科 → **用规则直接判定，不麻烦 AI 模型**。

只有这句话模棱两可、规则全判不出来时，才会请 AI 模型来"判案"。模型会返回一个结构化结论：什么学科、新题还是续题、打算怎么回答。

### 第 3 步：定下"这一轮怎么教"

系统现在要决定：面对这道题，老师该怎么出手。它有两种走法：

- **快路径（已经很有把握）**：直接定下教法，不再反复问 AI。比如判定这是"新题"，那就按"先给一级提示"来。
- **慢路径（问题模糊）**：让 AI 模型自己一步步拿主意——"要不要先查教材？""要不要先给个提示？"每走一步它可以选做一个动作，直到它觉得"材料够了，可以组织回答了"才停。

定下的"教法"就是学生最终看到的教学方式，例如：**给提示（分 1 级/2 级）、讲概念、给一道例题、给一道练习题、直接批改**。

### 第 4 步：去教材库翻资料（需要时才做）

- 如果要讲一个**新知识点**——比如学生问"什么是方程"——系统会去教材知识库里把相关的解释、例题翻出来，塞给 AI 当参考。
- 如果是**追问刚才那道题**——比如"那步怎么来的"——一般**不重新翻教材**，直接用上一轮记下来的上下文就够了。

### 第 5 步：把"材料包"交给 AI，生成学生看到的回答

系统把下面这些东西打包成一个"材料包"送给 AI 模型：

> 你是一个耐心的老师，不许直接报答案，要一步一步引导
> + 刚才的判断结论（数学、新题）
> + 定的教法（给一级提示）
> + 教材里翻到的参考
> + 这段对话的前后文

模型读完，生成学生看到的回复。比如它可能会说：

> "想想看：要让等式左边只留下 2x，两边需要同时做什么？"

如果这段回答太长被系统截断了，它会自动重新生成一个更精炼的完整版。

### 第 6 步：记下来、存起来

回答生成后，系统做三件事收尾：

1. **更新记忆**：记下"现在在学数学、当前题目是 2x+3=11"。
2. **存档**：把这一轮完整记录下来（学生问了什么、老师回了什么、中间怎么判断的、翻了哪些教材），存进本地数据库，方便以后回看和做研究评估。
3. **显示**：聊天区出现老师的回复。

### 第 7 步：下一轮

学生如果接着问"那下一步呢？"，系统因为记得上一轮，会**带着上下文继续**，不需要把整节课重新想一遍。对你来说就是：**它能接得上话，而且更快**。

## 术语对照表（看代码或技术文档时对着查）

| 专业说法 | 大白话 |
| --- | --- |
| 快路由 / 快速路由（fast routing） | 用死规则立刻判断，不请 AI。只有规则判不出来的才麻烦 AI |
| 分类（classification） | 判断这次提问是什么性质（学科、新题还是续题） |
| 教学契约（teaching contract） | 这一轮"怎么教"的定案：给几级提示、还是讲概念、还是给例题 |
| 检索 / RAG | 去教材知识库里翻相关资料 |
| 上下文（context） | 这段对话的前后文，模型写回答时要参考的东西 |
| KV 缓存 | 记住这次对话已处理到的状态，下一轮接着用，不用从头算 |
| 备课批注 / 公开思考 | 页面那四格（题意/写法/资料/成稿），就是本流程第 2~4 步的实时过程 |
| 行为循环 / action loop | 慢路径：让模型一步步决定"接下来做什么" |
| 归档（archive） | 把这一轮完整记录存进本地数据库 |
