# 数字教师书桌 UI 与运行链路修复设计

## 目标

把 `teacher-agent-demo` 从 Streamlit 默认控件堆叠的原型页，升级为具有独立教育品牌识别的“数字教师书桌”，同时一次性解决以下问题：

1. 页面缺乏产品完成度和视觉辨识度。
2. 上下文容量与发送按钮重叠，且本地启动容量仍为 131072。
3. 公开思考内容只有阶段名称，缺少对用户有帮助的处理摘要。
4. 简单创作指导也触发 RAG，多次编排模型调用造成百秒级延迟。
5. 思考区域在一次请求中反复展开和收起。

## 视觉方向

采用用户确认的“数字教师书桌”方案，但不把生成效果图直接作为页面背景。视觉由可响应、可访问、可维护的 HTML/CSS 组件组成。

- 主色：米白纸张、深靛蓝墨色、少量朱砂红批注、玉绿色成功状态。
- 左侧：会话目录与日期索引，保留“今天 / 7 天内 / 30 天内”的真实会话分组。
- 中间：回答作为数字讲义排版，不使用厚重聊天卡片；用户消息采用右上方的便签式气泡。
- 思考区：位于回答正文左侧的“备课批注”轨道，完成后可收成窄书签。
- 输入区：底部独立浮层，容量、深度思考、联网状态在左侧，发送按钮在右侧，互不覆盖。
- 纹理只使用轻量 CSS，不加载大尺寸装饰背景图；移动端退化为单列聊天布局。
- 不显示 Streamlit 的 Deploy、Stop 和开发工具栏。

## 页面组件

### 会话目录

- 新建按钮文案为“新建一课”。
- 当前会话显示标题与更新时间；其他会话保持单行或双行截断。
- 选择会话只切换当前会话 ID，不复制、清空或串接其他会话内容。
- 日期标签是视觉索引，不是独立的数据源。

### 公开思考摘要

公开区域展示可复核的处理摘要，不展示模型私有逐字思维链、系统提示词或隐藏 token。

每轮最多组织为四个稳定段落：

1. **题意**：学科、任务类型、是否为追问，以及一条简短的用户意图概括。
2. **写法/策略**：本轮采用的教学或解题路径，例如“从画面、情绪、悬念三个方向改写”。
3. **资料**：检索模式、是否使用本地/联网资料、命中数、关键资料类型和跳过原因。
4. **成稿**：回答的内容结构以及已执行的确定性验证或修正。

公开事件由结构化白名单字段生成。任何模型自由文本在进入公开区前都经过长度、字段和敏感信息过滤。

### 思考区状态机

每个 `turn_id` 只有以下状态：

`idle -> running_expanded -> complete_collapsed`，异常时为 `failed_expanded`。

- 开始生成：展开且持续追加内容。
- 生成期间：任何事件更新都不得改变展开状态。
- 正常完成：只执行一次收起操作。
- 用户手动展开/收起：完成后尊重用户选择，后续页面 rerun 不得覆盖。
- 失败：保持展开并展示可重试错误。
- 删除现有“完成后先展开、写 session key、再 rerun、下一次又收起”的临时逻辑。

### 输入区与上下文容量

- 上下文胶囊位于输入区左下方的正常布局流中，禁止绝对定位到发送按钮附近。
- 桌面端显示 `已用 / 上限`，窄屏只显示百分比，详情弹层展示精确 token。
- 主数字只读取本次模型服务实际启动容量，历史记录仅在详情中标注为旧配置。
- 本地一键启动目标容量改为 `524288`，并把实际 `--ctx-size` 同步到 Streamlit 环境。
- 启动失败不得回退成伪造的 512K；必须明确提示用户降低容量或检查 KV/显存配置。
- 线上 API 若只提供 128K，则显示真实 128K。

## RAG 路由与延迟预算

在执行检索前生成结构化 `RetrievalDecision`：

- `mode`: `none | local | local_then_web`
- `reason`: 可公开的一句话原因
- `confidence`: `0..1`
- `needs_current_information`: 是否依赖时效信息

### 路由规则

- 闲聊、普通追问、改写、润色、头脑风暴、基于用户已提供文本的讲解：`none`。
- 教材章节、题目证据、课程定义、相似练习、学生明确要求查资料：`local`。
- 用户明确要求最新信息，或答案确实依赖外部时效事实：`local_then_web`；无需先做无意义的本地搜索时可直接进入联网工具，但仍受单次预算约束。
- “本地相似度低”本身不能触发联网；必须同时存在具体且必要的证据缺口。
- 同一轮最多一次本地检索、一次联网检索；普通创作指导禁止联网。

### 延迟预算

- 路由判断不通过多轮自由编排循环完成，改为一次结构化决定加确定性守卫。
- 本地检索目标为 3 秒内。
- 联网检索硬超时为 12 秒；超时后使用已有知识继续并明确标注。
- 非数学创作类回答不进入无意义的数学验证与“安全修正”模型调用。
- 详情区分别显示路由、工具耗时、模型耗时和总耗时，不能再把多次编排模型耗时全部笼统算作 RAG。

## 数据与边界

- 会话仍以唯一 `conversation_id` 隔离；只读取当前 ID 对应的 episode。
- `turn_id` 用于思考 UI 状态，不能跨会话复用 UI 状态键。
- `PrototypeTurnRecord` 增加结构化检索决策和公开摘要字段时，旧会话缺失字段必须使用安全默认值加载。
- math checker、教学不变式和 evaluation 不做弱化。
- RAG 仍是教学辅助，不能覆盖确定性验证结果。

## 测试与验收

### UI

- 桌面 1440、1920、2048 宽度无横向溢出；输入控件之间至少保留 12px 间距。
- 390px 移动宽度下变为单列；容量胶囊和发送按钮不重叠。
- 页面不存在 Streamlit Deploy/Stop 工具栏。
- 会话切换、新建会话、连续两轮追问后消息均不消失、不串话。

### 思考区

- 单次请求的展开状态序列严格为一次展开、一次完成收起。
- 每轮公开摘要包含题意、策略、资料、成稿四类内容中的适用项。
- 测试保证系统提示、原始推理字段和未白名单 details 不进入公开摘要。

### 上下文

- 启动器默认值、模型服务参数、Streamlit 环境和 UI 主数字一致为实际值。
- 512K 启动配置对应 `524288`；历史 128K 元数据不能覆盖当前 512K。

### RAG

- 作文改写用例选择 `none`，不调用本地或联网检索。
- 教材证据用例选择 `local`。
- 最新时效资料用例才允许 `local_then_web`。
- 联网工具 12 秒超时后正常生成回答。
- 阶段计时能区分路由模型耗时和真实检索工具耗时。

### 回归

- `python -m pytest`
- `python scripts/run_eval.py`
- 启动服务后检查 HTTP 200，并手动完成新会话、连续追问、会话切换和思考区状态验收。

## 非目标

- 不复刻生成稿中的手写字体到所有正文。
- 不引入大型前端框架或替换 Streamlit 后端。
- 不展示原始私有思维链。
- 不在本次工作中重构整个 Teacher Agent 核心架构。
